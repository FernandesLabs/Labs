## How to use this report

1. Start with clusters that already have demand but no clicks (position 11–30 is a near-miss; 70+ needs a content/authority plan, not a title tweak).
2. Verify the page that owns each query in Search Console, then compare its title, H1, first paragraph and actual capabilities with the search intent. Add useful explanations rather than repeated query variants.
3. Treat blog posts and tool pages separately: a guide should answer the informational query and link to the tool; the tool should own the transactional query.
4. Re-run this script after each export and commit the generated report under `docs/seo/` so changes are reviewable.
